Get started in a minute

Python 3.10+ and nothing else, on Linux or macOS. One command installs it, no root, no git, nothing added to your project.

  1. Install and run. The first launch opens the setup page in your browser.
  2. Pick a provider. Paste an API key, or use Ollama or a CLI agent detected on your machine.
  3. Create a site. Start from a template or a blank page in a short wizard, or add a folder you already have.
  4. Open it and ask. “Make the hero title red.” Watch it change, undo if you don’t like it.
# install (Linux, macOS)
curl -fsSL https://ybucaille.github.io/livequill/install.sh | sh

# start the dashboard
livequill

# or open a project directly
livequill ~/projects/my-site
livequill --proxy http://localhost:5173 ~/projects/my-app

# or: pipx install livequill
